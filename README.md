# hbd-ayu

A handcrafted, digital birthday scrapbook surprise with playful interactions, interactive passcode unlocking, and personalized photo memories.

## Features

- **Interactive Passcode Lock**: Secret keypad entry to begin the birthday surprise experience.
- **Dynamic Question & Reveal**: Animated birthday greeting with celebration animations.
- **Cake & Candle Wishes**: Interactive birthday cake with blowable candle animation.
- **Gift Selection & Surprise Boxes**: Unwrap custom virtual birthday gifts.
- **Personalized Scrapbook Collage**: Custom scrapbook collage displaying authentic memories with tape, rotation, and note styling.
- **In-App Photo Customizer**: Reorder, replace, and caption memories on the fly.

## Development

Run the local development server:

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
```

## Tech Stack

- TanStack Start & React 19
- TypeScript
- Tailwind CSS
- Vite
